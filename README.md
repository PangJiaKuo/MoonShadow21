# 月影二十一 · Moonshadow 21

多人在线「魔改 21 点」卡牌游戏。当前交付：**阶段 1（核心引擎 + 热座对战）+ 阶段 2（特殊卡系统）+ 阶段 3（在线房间与联机）+ 阶段 4（用户系统与卡牌收藏）+ 阶段 4.5（卡组系统与商城）**。

> 神秘 · 复古 · 蒸汽朋克 + 塔罗风格。深色背景、金色描边、卡牌 3D 翻转动画。

## 四、运行

前置：Node.js ≥ 18（建议 ≥ 20）。

```bash
# 1. 安装依赖（在仓库根目录）
npm install

# 2. 启动后端（联机必须）
npm run dev:server        # http://localhost:4000/health

# 3. 启动前端
npm run dev:client        # http://localhost:5173
```

前端与后端分别开后，浏览器打开 `http://localhost:5173`：
- **本地热座**：无需后端，填写双方昵称直接开始。
- **在线对战**：点击「创建房间」选择房间人数（2-8 人，可选密码），生成 6 位房间码发给朋友；朋友在另一浏览器/标签页输入房间码「加入房间」。所有人「准备」后房主「开始对局」即可联机对战。刷新页面可自动重连恢复。
- **人机对战**：主菜单「人机对战 · 单机挑战电脑」，无需后端，填写昵称即可对战（可开关特殊卡）。

> 联机支持 2-8 人：2 人对赌、3-4 人积分制（先到 3 分获胜）、5-8 人淘汰制；创建房间时房主可在「模式」下拉中手动指定「积分赛（筹码）」等，未指定则按入座人数自动选择。

### 账号 / 卡组 / 商城（阶段 4 + 4.5）

- **注册 / 登录**：主菜单右上角「登录 / 注册」。注册仅需「昵称 + 密码」（密码最小 4 位），注册即自动建立默认 52 张卡组（4 花色 × 13，不含皇帝皇后）。
- **卡组**：主菜单用户栏「卡组」，展示你的卡组（52 张基础牌 + 已购买的特殊卡，每人独立、抽牌不重复）；游客默认显示基础 52 张。
- **商城**：「商城」以 **100 金币**购买现有 10 张特殊卡；购买后进入「已拥有特殊卡」区（不自动进卡组），金币即时扣减。
- **装备**：卡组页「已拥有特殊卡」区点击「装备」选中特殊卡，再点击卡组中一张同点数的牌完成替换；被替换的基础牌移出卡组，替换目标也可是一张已放入的同点特殊卡。
- **我的收藏**：仅展示已拥有的卡牌。
- **对局胜利金币**：登录账号加入联机对局，对局结束产生最终胜者时，胜者账号 +5 金币。
- 登录态持久化在浏览器 `localStorage`，刷新后自动恢复；退出需点「退出」。

> 阶段 4 / 4.5 REST API（前缀 `http://localhost:4000/api`）：
> `POST /auth/register`、`POST /auth/login`、`GET /auth/me`、`POST /auth/logout`、`GET /cards`（公开，可选 Bearer 显示拥有数）、`GET /collection`（需 Bearer）、`GET /deck`（需 Bearer，个人卡组）、`GET /shop`（需 Bearer，商城商品）、`POST /shop/buy`（需 Bearer，body `{cardId}`，购买入拥有区）、`POST /deck/equip`（需 Bearer，body `{cardId, targetCardId}`，装备替换同点数卡）。

## 五、玩法规则

### 基础规则

- 牌堆 54 张：太阳 ☀ / 月亮 🌙 / 星辰 ⭐ / 花朵 🌸 各 13 张 + 皇帝、皇后各 1 张。
- 数字牌 A=1、2-10 面值；人头牌 J=11、Q=12、K=13。
- 皇帝 / 皇后：可当作 0-13 任意点数（行动前须设定）。
- 目标：点数总和尽量接近 21，不超 21；超过即爆牌；恰好 21 为黑杰克。
- 开局每人 1 张暗牌（对对手保密，自己可见）；此后摸牌立即翻开（含特殊卡）。
- 轮流行动：抽牌（Hit）/ 停牌（Stand）。点数超过 21 不立即判负，而是自动停牌。
- 全部停牌后统一结算，结算时揭晓是否爆牌；点数最接近 21 且未爆者获胜；同分平局。
- **多人模式**（默认按入座人数自动选择）：2 人对赌轮流坐庄；3-4 人积分制每局赢家 +1 分、先到 3 分获胜；5-8 人淘汰制，爆牌或点数最低者出局。
- **积分赛（筹码押注）**（新增可选模式，2-8 人通用）：初始每人 10 币；每轮每人自动投入 1 币底注；停牌后可在加注弹窗中自定义加注（≤ 当前持有币数）；本局唯一胜者赢得本轮全部奖池（输家失去本轮投入），平局则均分奖池（余数留桌滚存），全员爆牌时奖池滚存到下轮；币数用尽者出局，最终仅剩 1 人时整场获胜。

### 特殊卡系统

- 特殊卡**不再**默认洗入全局牌堆；登录玩家通过**商城**购买后先进入「已拥有特殊卡」区，在卡组页点击「装备」替换卡组中一张同点数牌后进入个人卡组（每人从自己卡组抽牌且不重复）。本地热座 / 人机开启特殊卡时，把全部 10 张一并加入双方个人卡组以便体验。
- 每张特殊卡有固定点数（用于替换同点数普通卡），带稀有度：普通 / 稀有 / 史诗 / 传说（前端以不同描边颜色区分）。
- 摸到 OnDraw 特殊卡时视情况发动（可选不使用）；需要玩家选择时，引擎产出 `pending` 决策，前端弹出模态框，提交 `resolveChoice` 后继续流程。

#### 首批 10 张特殊卡（《创始系列》，原创）

| 卡 | 稀有度 | 触发 | 效果 |
|---|---|---|---|
| 银月 | 传说 | OnDraw | 将此牌点数设为 1-5 |
| 蒸汽核心 | 史诗 | OnDraw | 手牌全为太阳时设为 9 或 10 |
| 替身 | 稀有 | OnDraw | 与对手一张暗牌互换 |
| 命运硬币 | 稀有 | OnDraw | 弃一张手牌并重抽一张 |
| 沉默 | 史诗 | Passive | 对手特殊卡效果无效 |
| 双生 | 传说 | OnDraw | 拆成两张点数减半的牌 |
| 回溯 | 稀有 | OnStand | 停牌时弃一张重抽（仍停牌） |
| 赌徒 | 史诗 | OnDraw | 声明加倍：未爆则总点数×2，爆则出局 |
| 守夜人 | 传说 | OnCompare | 对手 21 点时强制其重抽 |
| 皇帝密令 | 史诗 | OnDraw | 点数固定 13，本回合必须抽牌 |

### 联机系统（阶段 3）

- **房间机制**：创建生成 6 位房间码（去易混字符），可设密码，可选房间人数（2-8）；输入房间码加入；大厅显示玩家/准备状态。
- **服务器权威**：`server/src/index.ts` 持有 `GameState`，客户端只发 `game:action` 指令，服务端用引擎 `apply` 计算后广播全房间，非法动作被忽略——客户端无法篡改结果。
- **多人模式**：`room:start` 优先使用房主在创建房间时指定的模式，未指定则按入座人数自动选择 `duel`（2 人）/ `points`（3-4 人，先到 3 分）/ `elimination`（5-8 人）。
- **断线重连**：断线后座位保留 60 秒；客户端把 `roomCode + playerId` 存到 `localStorage`，页面刷新后自动 `room:rejoin` 恢复房间与对局。

## 六、引擎设计说明

- `apply(game, action)` 为纯函数：返回新 `GameState`，不可变、可重放、可测试。
- 所有洗牌、发牌、结算、特殊卡效果都在引擎完成（服务器权威模式的前置）。
- 随机源可注入（`createGame(names, config, { rng })`），便于确定性测试。
- 效果引擎 `engine/src/effects.ts` 采用策略模式：`HANDLERS` 按 `EffectType` 分发，`processUnresolvedDraw / handleOnStand / handleOnCompare` 在正确时机触发，`resolveDecision` 结算玩家选择。
- 特殊卡数据集中在 `engine/src/specialCards.ts`，通过 `SPECIAL_BY_ID` 索引。

### 如何添加新特殊卡

1. 在 `engine/src/specialCards.ts` 的 `SPECIAL_CARDS` 数组中新增一项，填好 `id / name / rarity / effect{trigger,type,params} / description`。
2. 若效果类型是全新的，在 `engine/src/effects.ts` 增加对应 handler 并注册到 `HANDLERS`，并在 `shared/src/types.ts` 的 `EffectType` 联合类型中补充。
3. 在 `engine/test/specialCards.test.ts` 新增该卡的单元测试（触发时机 + 结算 + 边界）。
4. 运行 `npm run test` 与 `npm run typecheck` 验证。
